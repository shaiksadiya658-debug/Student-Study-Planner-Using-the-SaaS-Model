# Student Study Planner — SaaS Model Mini Project

## Project overview
A beginner-friendly student project that helps students organize study tasks, set due dates, choose priorities, and track completion progress. It demonstrates the idea of a SaaS (Software as a Service) product using a simple front-end prototype.

## Technologies
- HTML: page structure
- CSS: responsive layout and styling
- JavaScript: task management, filters, progress calculation
- Browser localStorage: saves tasks on the same browser/device

## Features
1. Add study tasks with subject, due date, duration, and priority.
2. Mark tasks as completed.
3. Delete tasks.
4. Filter all, pending, and completed tasks.
5. View total, completed, pending, and completion percentage.
6. Save tasks in the browser after refreshing the page.
7. Responsive design for mobile and desktop screens.

## How to run
1. Extract the ZIP file.
2. Open the `index.html` file in a modern browser.
3. Add a task using the form.

No installation or server is required for this demo.

## SaaS model explanation
A production SaaS version would be hosted online and accessed through a browser. Each student could sign in and access their study plan from different devices. This demo is the front-end prototype only; it does not include user accounts, cloud storage, or a backend server.
